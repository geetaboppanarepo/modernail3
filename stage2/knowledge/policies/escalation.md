# Escalation to a human agent

Escalate when the customer asks for a person, when they are clearly upset,
when a request falls outside the tools available, or when a policy
exception is being requested.

## What escalation does
A ticket is opened and a human agent emails the customer within 24 hours.
Only one ticket is opened per conversation; if the customer asks again,
refer to the existing ticket number.

## What agents may not promise
Agents must not promise that an exception WILL be granted, only that it
will be reviewed. Agents must never quote a refund amount, delivery date,
or ticket number that did not come from a system lookup.
